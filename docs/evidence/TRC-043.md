# Evidence: TRC-043 (Tenant isolation)

## Feature Description
Tenant isolation model and schema: PostgreSQL tables `tenants`, `spans`, and `traces` with PostgreSQL 16 Row-Level Security (RLS) policies enforcing multi-tenant isolation. Prevents cross-tenant access both at application layer and directly at the database engine level.

## Verification Level
`REAL` — verified against real PostgreSQL 16 instance (`trc-postgres-14` on port 5414) using native PostgreSQL Row-Level Security (`app.current_tenant` session variable).

## Files Touched
- `backend/src/storage/models.py`: SQLAlchemy declarative models for Tenant, ApiKey, SpanRecord, TraceRecord with multi-tenant keys.
- `backend/src/storage/db.py`: Async PostgreSQL database engine, session manager, and RLS session configuration.
- `backend/src/security/tenant.py`: TenantService with app-level validation and lookup.
- `backend/alembic/versions/001_initial_schema.py`: Migration creating tables and RLS policies.
- `backend/tests/test_tenant_isolation.py`: Negative and positive test cases for tenant isolation.
