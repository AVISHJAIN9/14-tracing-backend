# Evidence: TRC-054 (Payload size limits)

## Feature Description
Payload size and cardinality limit enforcement service. Protects collectors and storage against excessive payload size denial-of-service and memory spikes by enforcing maximum request byte sizes (raising `PayloadTooLargeError`), capping maximum attributes count per span, truncating strings exceeding byte limits with `...[TRUNCATED]` markers, and bounding event/link lists before persisting to PostgreSQL.

## Verification Level
`REAL` — verified against real PostgreSQL 16 database (`trc-postgres-14` on port 5414) with real multi-tenant `spans` persistence and retrieval.

- `backend/src/security/payload_limiter.py`: PayloadLimitsConfig, PayloadLimiter, and truncation logic.
- `backend/tests/test_payload_size_limits.py`: Byte limit rejection, string/cardinality truncation, and Postgres persistence proof tests.
