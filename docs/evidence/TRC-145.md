# TRC-145: Semantic Trace Search

## Verification Level
`REAL`

## Summary
Semantic trace search synthesizes rich textual execution signatures across trace topologies and embeds them into 384-dimensional dense vectors using the official `sentence-transformers` `all-MiniLM-L6-v2` neural model. Computes normalized cosine similarities to rank traces against natural-language queries (e.g. database deadlocks, token verification errors).
