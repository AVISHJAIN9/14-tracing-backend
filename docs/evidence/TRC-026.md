# Evidence: TRC-026 - Invalid context handling

## Feature Overview
- **ID**: TRC-026
- **Name**: Invalid context handling
- **Layer**: BE
- **Priority**: P0
- **Verification Level**: REAL

## Implementation Summary
- Created `tracelib.propagation.fallback` implementing `extract_or_create_root()`.
- Enforces strict hard invariant: invalid or missing context headers always start a new root trace and never crash.
- Handles all malformed context variations:
  - All-zero trace IDs or span IDs.
  - Forbidden version values (`ff`).
  - Corrupted, non-hex, or truncated header strings.
  - Non-string or unexpected carrier types without unhandled exceptions.
- Generates a new root `TraceContext` using CSPRNG IDs with `is_remote=False`.
