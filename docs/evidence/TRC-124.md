## Summary
Critical-path analysis computes the longest causal chain of dependent spans through a distributed execution DAG that accounts for the overall latency bottleneck. The backend provides an analytical dynamic programming traversal calculating critical path span sequences, while the frontend highlights the critical path in the trace viewer, identifying bottleneck segments with latency proportions.
