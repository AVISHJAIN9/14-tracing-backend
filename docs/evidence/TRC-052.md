# Evidence: TRC-052 (PII filtering)

## Feature Description
Personally Identifiable Information (PII) pattern detection and sanitization engine. Automatically inspects string attributes, event data, and status messages, replacing emails, US Social Security Numbers, payment card numbers, phone numbers, and IP addresses with secure redaction placeholders (`[EMAIL_REDACTED]`, `[SSN_REDACTED]`, `[CARD_REDACTED]`, etc.) before persistence.

## Verification Level
`REAL` — verified against real PostgreSQL 16 database (`trc-postgres-14` on port 5414) with direct raw SQL inspection of stored `spans.attributes` and `spans.status_message` columns proving zero plaintext PII leakage.
