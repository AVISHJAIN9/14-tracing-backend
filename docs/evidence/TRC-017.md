## Implementation Summary
- Created `tracelib.propagation.tracestate` providing `parse_tracestate_header()` and `parse_tracestate_headers()`.
- Implemented W3C tracestate grammar parsing and validation:
  - Supports comma-separated list-members with whitespace stripping.
  - Supports simple keys (`vendor`) and tenant-qualified keys (`vendor@system`).
  - Strict value validation: ASCII 0x20 to 0x7E without commas or equal signs.
  - Duplicate key resolution: preserves the first occurrence per W3C specification.
  - Tolerant parsing: skips malformed members gracefully without failing the entire header.
  - Multi-line header parsing via `parse_tracestate_headers()`.
  - Max 32 list-members constraint enforced.
