## Summary
Trace anomaly detection applies an unsupervised IsolationForest model trained on multivariate trace-level features (duration, span count, max depth, error count, and max fan-out). Successfully differentiates normal operational distributions from multidimensional trace execution outliers, outputting anomaly decision scores and explanatory bottleneck factors.
