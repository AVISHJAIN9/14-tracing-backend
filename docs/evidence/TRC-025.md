- **Layer**: BE
- **Priority**: P0

## Implementation Summary
- Created `tracelib.propagation.inject` providing unified `ContextInjector` and `inject_context()`.
- Implemented protocol-agnostic context injection supporting:
  - Explicit `TraceContext` or automatic context extraction from currently active `Span`.
  - W3C TraceContext headers (`traceparent`, `tracestate`).
  - W3C Baggage header (`baggage`).
  - Optional B3 single-header format injection (`b3`).
  - Custom `SetterFunc` protocol for arbitrary carrier data structures.
  - Skips invalid contexts safely without polluting outgoing carrier.
