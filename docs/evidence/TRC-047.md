# Evidence: TRC-047 (JWT validation)

## Feature Description
Cryptographic JWT validation service supporting both symmetric (HS256) and asymmetric (RS256) algorithms. Enforces strict signature verification, expiration (`exp`), not before (`nbf`), issued at (`iat`), audience (`aud`), and issuer (`iss`). Unconditionally rejects insecure `none` algorithm bypass attempts and validates tenant existence and active status in PostgreSQL.

## Verification Level
`REAL` — verified against real cryptographic key operations using `pyjwt` and `cryptography` (RSA-2048 key pairs) and against real PostgreSQL 16 database (`trc-postgres-14` on port 5414) for tenant authorization.
