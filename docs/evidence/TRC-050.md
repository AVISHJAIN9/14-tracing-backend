# Evidence: TRC-050 (Trace-level authorization)

## Feature Description
Fine-grained trace-level authorization service. Enforces service-level ownership scopes (e.g. allowing or restricting access to traces originated by `payment-service`) and security classification tags (e.g. `classification:confidential`, `classification:restricted`). Integrates with PostgreSQL database trace records and blocks unauthorized access with `TraceAccessDeniedError`.

## Verification Level
`REAL` — verified against real PostgreSQL 16 database (`trc-postgres-14` on port 5414) with real multi-tenant `traces` rows.
