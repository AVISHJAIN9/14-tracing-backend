## Implementation Summary
- Created `tracelib.propagation.traceparent` providing `Traceparent` and `parse_traceparent_header()`.
- Implemented full W3C traceparent grammar validation (`version-trace_id-parent_id-trace_flags`).
- Strict validation rules enforced:
  - Version `00` must have exactly 4 hyphen-separated fields.
  - Version `ff` is rejected per W3C specification.
  - Future versions (> `00`) accept forward-compatible extra fields while parsing core IDs.
  - Trace ID and parent ID cannot be all zeros (`00000000000000000000000000000000` / `0000000000000000`).
  - Trace flags must be valid 2-hex characters.
  - Hex values normalized to lowercase.
