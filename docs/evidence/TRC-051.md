# Evidence: TRC-051 (Sensitive attribute redaction)

## Feature Description
Sensitive attribute redaction engine that recursively masks or strips sensitive fields (e.g. `password`, `secret`, `token`, `api_key`, `credit_card`, `cvv`, `ssn`) across span attributes, nested dictionary objects, and arrays before persistence or transmission. Verified by raw PostgreSQL JSONB inspection proving plaintext secrets never reach disk.
