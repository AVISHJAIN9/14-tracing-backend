- **Layer**: BE
- **Priority**: P0

## Implementation Summary
- Created `tracelib.propagation.websocket` providing `WebSocketPropagator`.
- Implemented comprehensive two-phase WebSocket tracing propagation:
  1. Handshake Phase: Injects and extracts W3C TraceContext and Baggage across WebSocket HTTP upgrade handshake headers.
  2. Frame/Message Phase: Injects and extracts W3C TraceContext and Baggage via JSON frame metadata envelopes (default `_trace` or custom envelope key).
- Graceful error handling: non-dict messages or malformed envelopes return `None, None` safely without terminating active WebSocket connections.
