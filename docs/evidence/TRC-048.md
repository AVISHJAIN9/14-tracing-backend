# Evidence: TRC-048 (mTLS support)

## Feature Description
Mutual TLS (mTLS) client certificate verification and tenant identity extraction service. Verifies client certificate cryptographic signatures against trusted Root CA certificates, verifies validity intervals (`not_before`, `not_after`), extracts tenant identifiers from SAN URIs (`spiffe://tracing.dev/tenant/<id>`) and Subject Common Name (`CN`), and enforces tenant status in PostgreSQL storage.

## Verification Level
`REAL` — verified using X.509 certificates generated dynamically using `cryptography` (RSA-2048 with SHA-256) and verified against real PostgreSQL 16 database (`trc-postgres-14` on port 5414).

## Files Touched
- `backend/src/security/mtls.py`: MtlsService, MtlsAuthContext, SAN parsing, trust chain verification.
- `backend/tests/test_mtls_support.py`: Comprehensive test suite with root CA, signed client certs, rogue CA certs, and expired certs.
