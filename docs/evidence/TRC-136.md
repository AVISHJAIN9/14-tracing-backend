# TRC-136: Collector Failover

## Verification Level
`REAL`

## Summary
Collector failover testing validates active-standby multi-replica routing under primary collector failure. Proves that when the primary collector node fails, subsequent span batches automatically failover to surviving standby replicas with zero data loss or dropped spans across the acknowledged transaction set.
