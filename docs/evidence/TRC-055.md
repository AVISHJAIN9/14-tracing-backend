# Evidence: TRC-055 (Query rate limiting)

## Feature Description
Multi-tenant query rate limiter service backed by Redis 7 sliding window sorted sets and PostgreSQL tenant configuration. Protects search and query interfaces against high-concurrency request floods, enforces per-tenant limits configured in `tenants.settings`, ensures multi-tenant rate limit isolation, and calculates `retry_after` seconds upon quota exhaustion with `RateLimitExceededError`.

## Verification Level
`REAL` — verified against real Redis 7 instance (`trc-redis-14` on port 6314) and real PostgreSQL 16 database (`trc-postgres-14` on port 5414).
