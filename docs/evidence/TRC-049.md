# Evidence: TRC-049 (Role-based access)

## Feature Description
Role-based access control (RBAC) service implementing deny-by-default server-side authorization. Validates caller roles (`admin`, `ingest`, `query`, `readonly`) against granular permissions (`spans:ingest`, `spans:query`, `traces:query`, `spans:delete`, `api_keys:manage`, `tenants:manage`, `metrics:view`). Integrates directly with PostgreSQL `api_keys` role column and raises `AccessDeniedError` on privilege deficits.

## Verification Level
