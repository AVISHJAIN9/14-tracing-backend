# Evidence: TRC-045 (API-key authentication)

## Feature Description
API-key authentication service with Argon2id cryptographic hashing, secure prefixing, tenant binding, and revocation capabilities. Plaintext API keys are generated using CSPRNG and displayed once to the caller; only Argon2id hashes are persisted in the PostgreSQL `api_keys` table.

## Verification Level
`REAL` — verified against real PostgreSQL 16 database (`trc-postgres-14` on port 5414) and real Argon2id password hashing library (`argon2-cffi`).

## Files Touched
- `backend/src/security/api_key.py`: ApiKeyService, ApiKeyAuthContext, creation, authentication, and revocation.
- `backend/src/storage/models.py`: ApiKey model with prefix, key_hash, tenant relationship, and role columns.
- `backend/tests/test_api_key_auth.py`: Positive and negative test cases covering valid, tampered, invalid, and revoked keys.
