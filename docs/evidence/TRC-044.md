# Evidence: TRC-044 (Tenant-scoped trace IDs)

## Feature Description
Tenant-scoped trace ID model and storage implementation. All trace lookups and storage records require explicit `(tenant_id, trace_id)` composite keys. Allows multiple distinct tenants to ingest traces with identical 32-character hex trace IDs without key collision or cross-tenant data bleed.

## Verification Level
`REAL` — verified against real PostgreSQL 16 database (`trc-postgres-14` on port 5414) using native primary key `(tenant_id, trace_id)` on `traces` and `(tenant_id, trace_id, span_id)` on `spans`.
