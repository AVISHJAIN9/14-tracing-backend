# Evidence: TRC-027 - Missing parent handling

## Feature Overview
- **ID**: TRC-027
- **Name**: Missing parent handling
- **Layer**: BE
- **Priority**: P0
- **Verification Level**: REAL

## Implementation Summary
- Created `tracelib.propagation.carrier` providing `start_span_from_carrier()`.
- Added support for missing parent context handling:
  - If parent context is missing or carrier is empty/None, cleanly initializes a fresh root span.
  - Automatically generates CSPRNG trace ID and span ID with `parent_id=None` and `is_root=True`.
  - Preserves any propagated Baggage entries even when traceparent is missing.
  - When parent context is present and valid, properly links the span as a child with matching `trace_id` and `parent_id=parent.span_id`.
