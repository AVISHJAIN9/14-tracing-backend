## Summary
The Trace Tags Viewer component aggregates all attributes across all spans in an entire trace into a unified searchable and filterable tag cloud. It displays unique tag names, occurrences, and distinct value distributions, enabling operators to analyze multidimensional contextual tags (e.g. environment, service tier, auth method).
