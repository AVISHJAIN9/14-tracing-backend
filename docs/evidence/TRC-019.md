## Implementation Summary
- Created `tracelib.propagation.http` providing `HttpHeaderPropagator` and `normalize_http_headers()`.
- Implemented HTTP context propagation for W3C TraceContext and W3C Baggage across web frameworks and HTTP client interfaces:
  - Standard dictionary carrier support (requests, httpx, aiohttp).
  - Raw ASGI byte header sequence support (`List[Tuple[bytes, bytes]]`).
  - Byte-decoding with fallback (latin-1 / UTF-8) and case-insensitive header key normalization.
  - Injects `traceparent`, `tracestate`, and `baggage` headers.
  - Extracts active `TraceContext` and `Baggage` simultaneously.
