## Implementation Summary
- Created `tracelib.propagation.thread_context` providing thread-safe context propagation across thread pools and asynchronous worker threads.
- Implemented `wrap_callable_with_context()`: captures calling thread context via `contextvars.copy_context()` and runs callable in captured scope.
- Implemented `ContextThreadPoolExecutor`: subclass of `concurrent.futures.ThreadPoolExecutor` capturing submitter's context on `submit()` and `map()`.
- Verified thread isolation: raw threads do not inherit context by default, while thread pool executors and wrapped callables reliably propagate active spans without cross-thread contamination or leakage.
