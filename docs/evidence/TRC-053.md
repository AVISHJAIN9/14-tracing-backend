# Evidence: TRC-053 (Header redaction)

## Feature Description
Header redaction engine that masks sensitive HTTP and RPC headers (`authorization`, `cookie`, `set-cookie`, `proxy-authorization`, `x-api-key`, `x-auth-token`) across direct header dictionaries and OpenTelemetry span attributes (`http.request.header.*`, `http.response.header.*`). Validated by inserting spans with sensitive header attributes into PostgreSQL and proving via raw queries that sensitive tokens never reach database disk.

## Verification Level
`REAL` — verified against real PostgreSQL 16 database (`trc-postgres-14` on port 5414) with raw SQL inspection of `spans.attributes` JSONB storage.
