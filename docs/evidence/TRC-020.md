## Implementation Summary
- Created `tracelib.propagation.grpc` providing `GrpcMetadataPropagator` and `normalize_grpc_metadata()`.
- Implemented gRPC metadata propagation for W3C TraceContext and W3C Baggage across gRPC client and server interceptors:
  - Supports standard gRPC metadata format as sequences of key-value tuples (`List[Tuple[str, str]]`).
  - Supports dictionary-based metadata representations.
  - Normalizes keys case-insensitively and decodes bytes headers safely.
  - Injects `traceparent`, `tracestate`, and `baggage` metadata entries.
  - Extracts active `TraceContext` and `Baggage` from gRPC metadata.
