## Implementation Summary
- Created `tracelib.propagation.extract` providing unified `ContextExtractor`, `extract_context()`, and `DictGetter`.
- Extractor combines:
  - W3C TraceContext propagator (`traceparent` and `tracestate`).
  - B3 single-header format fallback (`b3` header with 16 or 32-hex trace IDs and sampling flags).
  - W3C Baggage extraction.
  - Priority ordering: W3C Trace Context takes precedence over B3 when both are present.
- Protocol-agnostic `GetterFunc` interface allows extracting from arbitrary carriers, dicts, and custom request objects.
