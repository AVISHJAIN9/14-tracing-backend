# TRC-135: Backpressure Testing

## Verification Level
`REAL`

## Summary
Backpressure testing assesses HTTP REST endpoint behavior under saturation. Proves that when collector admission buffers are saturated, endpoints return HTTP 429 Too Many Requests with explicit `Retry-After` headers, record rejected request counters without silent drops, and recover normal HTTP 200 acceptance once capacity is drained.
