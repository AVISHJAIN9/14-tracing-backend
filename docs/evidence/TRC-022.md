## Implementation Summary
- Created `tracelib.propagation.async_context` utilizing Python's native `contextvars.ContextVar`.
- Implemented core async context functions:
  - `get_current_span()`: accesses active span in current coroutine/task context.
  - `attach_span()`: attaches span returning a restoration `Token`.
  - `detach_span()`: restores previous context via `ContextVar.reset(token)`.
  - `use_span()`: unified dual sync and async context manager (`__enter__` / `__exit__` and `__aenter__` / `__aexit__`).
- Fully isolated across concurrent tasks executing under `asyncio.gather` and nested context boundaries.
