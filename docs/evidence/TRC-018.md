## Implementation Summary
- Created `tracelib.propagation.baggage` providing `Baggage`, `BaggageEntry`, and `W3CBaggagePropagator`.
- Compliant with W3C Baggage recommendation:
  - Immutable baggage data model maintaining key, value, and optional metadata properties.
  - Strict key validation using RFC 7230 token specification (`KEY_PATTERN`).
  - Serializes to standard W3C `baggage` header string (`key=value;prop1=v1,key2=value2`).
  - Tolerant header parsing ignoring malformed members without failing entire header.
  - `W3CBaggagePropagator` with `inject()` and `extract()` across mapping carriers with case-insensitive header lookup.
